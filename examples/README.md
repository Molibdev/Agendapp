# Datos de demostración

`agendapp-datos-prueba-v0.12.0.json` es el respaldo integral recomendado para probar la versión 0.12.0. Sus datos son ficticios y tienen como fecha de referencia el 5 de noviembre de 2026.

Incluye cuatro tipos de cuenta, categorías personalizadas, 89 movimientos, presupuestos, metas y aportes, una transferencia, pagos recurrentes activos y pausados, compras en cuotas activas y pagadas, un prepago archivado y cinco eventos de Agenda. También contiene un movimiento futuro para comprobar que los informes respetan la fecha de corte.

Para cargarlo, abre **Ajustes → Copias de seguridad → Cargar copia JSON**, revisa el resumen y confirma la restauración. La confirmación reemplaza el perfil local activo. El archivo no contiene sesiones, permisos de Google, credenciales, preferencias de apariencia ni la opción de bloqueo biométrico.

El formato del respaldo sigue siendo `qgasto-backup` versión 1. Esa versión identifica el contrato de datos y es independiente de la versión 0.12.0 de la aplicación.

`qgasto-datos-prueba.json` se conserva como muestra histórica para pruebas de compatibilidad.
